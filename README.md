# Домашнее задание №1
Расширение Third Person Template.
Движок: Unreal Engine 5.x.
## Выполнено
- Создан C++ класс AMechanicsCharacter, наследующий ACharacter.
- BP_ThirdPersonCharacter переведён на новый родительский класс.
- Добавлены действия IA_Sprint и IA_Interact через Enhanced Input.
- Привязка новых действий выполнена в C++ через BindAction.
- Реализован Dynamic Multicast Delegate для взаимодействия.
- При взаимодействии Blueprint выводит Interaction triggered!
- Реализованы изменение скорости и переменная bIsSprinting.
- Добавлена State Machine с состояниями Normal и Sprint.
- Реализована выносливость с расходом и восстановлением.
- При нулевой выносливости спринт прекращается.
- Значение выносливости выводится на экран во время Play.
## Управление
- WASD: перемещение.
- Мышь: управление камерой.
- Пробел: прыжок.
- Left Shift: спринт при удержании.
- E: взаимодействие.
## Выносливость
Максимальное значение: 100.
Расход при спринте: 25 единиц в секунду.
Восстановление: 15 единиц в секунду.
После истощения нужно отпустить Left Shift и нажать снова.
## Запуск
1. Установить указанную версию Unreal Engine и компоненты C++.
2. Сгенерировать файлы Visual Studio для MechanicsHW.uproject.
3. Собрать проект в конфигурации Development Editor, Win64.
4. Открыть MechanicsHW.uproject.
5. Открыть карту шаблона Third Person и нажать Play.
