# Домашнее задание №2
Расширение Third Person Template.
Движок: Unreal Engine 5.x.
## Выполнено
- Создан C++ класс AMechanicsCharacter, наследующий ACharacter.
- BP_ThirdPersonCharacter переведён на новый родительский класс.
- Добавлены действия IA_Sprint и IA_Interact через Enhanced Input.
- Привязка новых действий выполнена в C++ через BindAction.
- Реализован Dynamic Multicast Delegate для взаимодействия.
- При взаимодействии Blueprint выводит Interaction triggered!
- Реализованы изменение скорости и переменная bIsSprinting.
- Добавлена State Machine с состояниями Normal и Sprint.
- Реализована выносливость с расходом и восстановлением.
- При нулевой выносливости спринт прекращается.
- Значение выносливости выводится на экран во время Play.
## Управление
- WASD: перемещение.
- Мышь: управление камерой.
- Пробел: прыжок.
- Left Shift: спринт при удержании.
- E: взаимодействие.
## Выносливость
Максимальное значение: 100.
Расход при спринте: 25 единиц в секунду.
Восстановление: 15 единиц в секунду.
После истощения нужно отпустить Left Shift и нажать снова.
## Запуск
1. Установить указанную версию Unreal Engine и компоненты C++.
2. Сгенерировать файлы Visual Studio для MechanicsHW.uproject.
3. Собрать проект в конфигурации Development Editor, Win64.
4. Открыть MechanicsHW.uproject.
5. Открыть карту шаблона Third Person и нажать Play.


## Домашнее задание 2: Behavior Trees и PCG
Уровень: Content/HW2/Maps/L_HW2.
Окружение создаётся графом PCG_Props. На поверхности пола процедурно размещаются коробки с коллизиями. Изменение Seed у PCG_PropsVolume меняет расстановку.
Для передвижения ИИ используется NavMeshBoundsVolume. Навигация учитывает процедурные препятствия.
Персонаж ИИ создан на основе C++-класса LabAICharacter. Контроллер LabAIController запускает BT_Enemy с Blackboard BB_Enemy.
### Поведение
ИИ патрулирует территорию в радиусе 1000 единиц вокруг стартовой точки.
При приближении игрока на расстояние 1200 единиц ИИ начинает преследование.
При удалении игрока более чем на 1800 единиц ИИ возвращается к патрулированию.
Скорость патрулирования составляет 300, преследования — 550.
### Дополнительное поведение Flee
При нажатии E на расстоянии до 800 единиц ИИ пугается и убегает в течение 5 секунд со скоростью 700.
Реакция подключена к делегату OnInteraction из первого задания.
Собственный C++ Service BTService_UpdateAI обновляет Blackboard каждые 0.2 секунды.
Собственный C++ Task BTTask_FindAIPoint выбирает точки патрулирования и бегства.
Для бегства проверяются до 20 случайных достижимых точек в радиусе 1000 единиц. Выбирается точка, наиболее удалённая от игрока и расположенная дальше текущего положения ИИ.
Если подходящая точка не найдена, ИИ остаётся на месте до следующей попытки.
Ветки Behavior Tree расположены по приоритету: Flee, Chase, Patrol.
### Проверка
1. Открыть L_HW2 и запустить игру.
2. Издалека наблюдать патрулирование.
3. Подойти к ИИ и проверить преследование.
4. Пробежать возле коробок и проверить обход препятствий.
5. Убежать дальше радиуса потери цели и проверить возврат к патрулированию.
6. Подойти ближе 800 единиц, нажать E и проверить бегство.
